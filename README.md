# Conversor de Unidades de Longitud

Una aplicación de escritorio gráfica desarrollada en Python utilizando **Tkinter** para realizar conversiones sencillas e intuitivas entre distintas unidades de longitud:

- Milímetros (mm)
- Centímetros (cm)
- Metros (m)

---

## Características

- **Interfaz gráfica intuitiva y limpia**: desarrollada con Tkinter y ttk.
- **Soporte para decimales**: admite comas (`,`) y puntos (`.`) como separadores decimales.
- **Validación de errores**: advertencias emergentes si se introduce un valor no numérico.
- **Acciones rápidas**: botón de cálculo y botón para limpiar los campos y reiniciar el formulario.

---

## Requisitos

- Python 3.x instalado en el sistema.
- Tkinter (incluido por defecto en la mayoría de instalaciones estándar de Python para Windows).

---

## Cómo ejecutar la aplicación

1. Clona el repositorio o descarga los archivos:
   ```bash
   git clone https://github.com/abdell28/conversor-unidades.git
   cd conversor-unidades
   ```

2. Ejecuta el archivo principal:
   ```bash
   python Untitled-1.py
   ```
